# LDT review handoffs

Download the Windows x64 review ZIP from this repository's Releases page.

Extract the complete ZIP into a writable folder and launch **Start LDT Hub.cmd**. Keep all extracted files together. No Node.js, Git or VS Code installation is required.

This is an unsigned internal visual-review prototype, published here for easy download. Company services, login, Team Chat and Jarvis are not connected. Notes stay on the reviewer's device. See READ ME.txt and PACKAGING-NOTES.txt inside the archive for details and limitations. License notices are included in the package.
